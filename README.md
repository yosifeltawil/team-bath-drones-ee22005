# Team Bath Drones — Autonomous UAV Project

EE22005 portfolio evidence repository for the Team Bath Drones D&M Challenge 2025/26.

## Project overview

Autonomous fixed-wing UAV designed, built and tested as part of the
Team Bath Drones D&M Challenge. The aircraft completes autonomous waypoint
navigation, drops a 1 kg parachuted payload, and lands without human
intervention, all within a 5 kg MTOW, 2 m wingspan, and £100 component budget.

## Repository contents

- `BillOfMaterials.csv` — controlled bill of materials
- `ardupilot_params.txt` — flight controller parameter file
- `README.md` — this file
